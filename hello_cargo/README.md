# Веб-видеоредактор

Локальный видеоредактор на Rust. Выбери MP4, задай начало и конец
фрагмента, затем нажми «Выгрузить MP4», чтобы скачать обрезанное видео.

## Запуск

Для экспорта нужен FFmpeg с энкодерами `libx264` и `aac`. Для склейки также
нужен `ffprobe`, который обычно устанавливается вместе с FFmpeg.
Из папки `hello_cargo` запусти сервер:

```bash
cargo run
```

Открой <http://localhost:3000> в браузере на этом же компьютере.
Для остановки сервера нажми `Ctrl+C` в терминале.

## Как устроен запуск

- `#[tokio::main]` запускает среду Tokio для асинхронных операций.
- `Router` из Axum связывает `GET /` с обработчиком `index`.
- `TcpListener::bind` занимает адрес `127.0.0.1:3000` и слушает подключения.
- `axum::serve` принимает подключения и обрабатывает HTTP-запросы.
- `.await` ждёт завершения асинхронной операции, позволяя Tokio выполнять другие задачи.
- `?` возвращает ошибку из `main`, если операция завершилась неудачно.

Предыдущий консольный черновик сохранён в `drafts/trim.rs`. Он не участвует
в сборке; его зависимость `ffmpeg-rs` удалена из `Cargo.toml`.

## Как проходит экспорт

- `src/web/editor.js` открывает исходный файл в браузере и управляет ползунками.
- При экспорте форма отправляет файл и две границы в секундах на `POST /export`.
  Лимит тела запроса составляет 100 МиБ, включая поля формы.
- `src/main.rs` сохраняет видео во временную папку и запускает FFmpeg.
  Готовый фрагмент скачивается как `video-trimmed.mp4`.

## Склейка видео

Выбери два или больше MP4 и нажми «Склеить MP4». Ролики попадут в
`video-joined.mp4` в порядке, в котором браузер отправил файлы. Для каждого
запроса сервер создаёт отдельную временную папку. Лимит запроса составляет
100 МиБ на все файлы вместе с полями формы.

FFmpeg перекодирует входные ролики в общие параметры. Кадр сохраняет пропорции,
а недостающую область заполняют чёрные поля. Если только часть роликов имеет
звук, остальные фрагменты воспроизводятся с тишиной.
